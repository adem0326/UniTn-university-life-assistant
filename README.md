# SmartCampus – University Life Assistant

SmartCampus is a cross-platform university community application designed to connect students from different universities in one digital space.

The application aims to simplify student life by providing a platform for communication, collaboration, sharing resources, and discovering opportunities.

## Features

- **Student Authentication:** Create an account and log in using email.
- **Student Profiles:** Manage personal and academic information.
- **Community:** Share posts, interact with other students, and exchange ideas.
- **Communication:** Connect and communicate with other students.
- **Study Groups:** Create or join groups to collaborate and study together.
- **Bookmarks:** Save useful posts and resources for later.
- **Marketplace:** Buy, sell, and exchange items between students.
- **AI Integration:** Provide intelligent assistance to improve the student experience.

## Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or VS Code
- Firebase account

### Installation

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Navigate to the project directory:

```bash
cd uni_tn
```

3. Install dependencies:

```bash
flutter pub get
```

4. Run the application:

```bash
flutter run
```
